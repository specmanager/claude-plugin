# List Projects

List all your specmanager projects.

## Instructions

1. Use `mcp__specmanager__list-projects` to get all projects.

2. Display projects in a clear format showing:
   - Project name
   - Project ID
   - Linked repository (if any)
   - Task counts if available

3. Highlight the current project if the working directory matches a linked repo.

4. Tip: Use `/tasks` in a project directory to see its pending tasks.
